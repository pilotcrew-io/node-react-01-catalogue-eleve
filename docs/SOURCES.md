# Sources officielles et lecture utile

Références consultées pour la rédaction le **12 octobre 2026**. Les tutoriels sont des exercices originaux ; la documentation décrit les outils, pas une solution complète au magasin fictif. Vérifier les versions exactes dans vos manifests et lockfiles.

- [Express — API 5.x](https://expressjs.com/en/5x/api/) — Routes, corps JSON, réponses et middlewares de l’API locale.
- [Node.js — Test runner](https://nodejs.org/api/test.html) — Exécuter et isoler les tests natifs Node ; vérifier les options dans la version 22 utilisée par le projet.
- [React — Managing State](https://react.dev/learn/managing-state) — Éviter les états redondants et organiser la circulation des données.
- [React — useEffect](https://react.dev/reference/react/useEffect) — Dépendances, nettoyage des effets et réponses réseau tardives.
- [TypeScript — Narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html) — Réduire un unknown après vérification et représenter les états par variantes.
- [Vite — Getting Started](https://vite.dev/guide/) — Créer le frontend React/TypeScript et vérifier les prérequis Node de la version retenue.
- [W3C WAI — Forms Tutorial](https://www.w3.org/WAI/tutorials/forms/) — Associer libellés, instructions, erreurs et actions aux contrôles.
- [W3C WAI — Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) — Annoncer un résultat ou une attente sans déplacer systématiquement le focus.
- [Testing Library — About Queries](https://testing-library.com/docs/queries/about/) — Rechercher les éléments par rôle et nom accessible, attendre les résultats asynchrones.
